# Midnight Farmer

A grid based guessing game! I created this while learning Python - I was inspired by the concept of 2D Lists and somehow that snowballed into this!


## The Story
You play as a malicious midnight gremlin who has snuck onto a rival farmer's land under the cover of darkness. Your mission? Plant as many invasive, sabotaging flowers as you can before the sun rises or you get caught!

## Features
* **Dynamic Grid Generation:** A new 5x5 layout every single run.
* **Difficulty Scaling:** Choose between Easy, Normal, and Hard modes.
* **Persistent Save System:** Tracks your high scores and win streaks between game sessions using JSON files.
* **Custom End-Game Share Cards:** Generates an emoji map of your performance to share with friends.

##  Concepts Learned
This was my very first official Python project! While building it, I mastered:
* 2D List Matrices and nested `for` loops.
* Game state loop handling with `while` and `break`.
* Data persistence using File I/O and JSON dictionaries.

A disclaimer - Replit hadled all visuals, HTML, etc - Replit also helped to add some features like a high score, difficulty levels, and JSON saves. My original script was purely a text based game.
